# Image Steganography Application

## 📌 Overview
A professional web-based steganography application that hides secret images inside cover images using LSB (Least Significant Bit) technique. The application provides a modern, user-friendly interface for both encoding and decoding hidden images.

## ✨ Features
- 🔒 Hide secret images inside cover images
- 🔓 Extract hidden images from steganographed images
- 🎨 Modern, responsive UI with drag-and-drop support
- 📊 Real-time image preview and statistics
- ⚡ Fast processing using LSB algorithm
- 🖼️ Support for PNG, JPG, JPEG, and BMP formats

## 🛠️ Technologies Used
- **Backend**: Python, Flask
- **Image Processing**: Pillow, NumPy
- **Frontend**: HTML5, CSS3, JavaScript
- **Steganography**: LSB (Least Significant Bit) technique

## 📋 Prerequisites
- Python 3.7 or higher
- pip (Python package manager)
